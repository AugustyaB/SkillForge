# Welcome to SkillForge

**SkillForge is your cross-IDE developer skill compass.**

When you're building a project or planning a new feature, you don't always know what libraries, frameworks, or tools are best for the job. SkillForge bridges that gap by analyzing your natural language intent and workspace context to recommend vetted, purposeful tools.

### What SkillForge Does For You:
- **Instant Intent-to-Tool Discovery**: Tell SkillForge what you want to build (e.g., *"real-time chat with WebSockets"*, *"fast async database queries"*, *"accessible design system"*), and receive ranked, verified suggestions.
- **100% Offline & Private by Default**: Over 350 curated, purposeful technologies are stored locally in an in-memory database with zero network transmission, zero tracking, and $<2\text{ms}$ query latency.
- **Battle-Tested Trust Seals**: Every recommendation is stamped with a transparent trust tier (**Verified**, **Validated**, **Suggested**) and real registry health metrics (GitHub stars, downloads, maintenance status).
- **One-Click Terminal Installation**: Run install commands directly in your scoped project folder with a single click.
