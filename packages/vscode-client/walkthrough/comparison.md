# Side-by-Side Tool Comparison & Bookmarks

Choosing between competing libraries (e.g., *FastAPI vs Django*, *React vs Vue vs Svelte*, *Zustand vs Redux Toolkit*) is one of the hardest decisions developers face.

### Technology Comparison Matrix:
- **Side-by-Side Evaluation**: Compare 2 to 3 candidate technologies directly inside VS Code across difficulty, ecosystem, downloads, stars, pros, and trade-offs.
- **Architectural Conflict Banners**: Prominent warning callouts when evaluating mutually exclusive libraries for the same architectural slot.
- **Deep Dive "vs" Chips**: Every skill card in the Suggestion Canvas features a collapsible *Related tools & resources* drawer with 1-click **vs** chips to compare it against alternatives immediately.
- **Dedicated Install Column Actions**: Directly run the winning library's terminal installation command without switching windows.

### Saved Bookmarks Library:
- Click the **Star icon** on any skill card to bookmark it to your personal developer library.
- Access bookmarked tools anytime from the **Bookmarks view** in the SkillForge Activity Bar.
